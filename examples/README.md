# Example prompts

These examples are intentionally outcome-focused. The skill should consult the current Kie AI documentation before choosing models or constructing payloads.

## Cost-conscious cinematic trailer

```text
Create a cinematic 10-second trailer of a lone astronaut walking across a red desert at dusk, with epic orchestral background music. Use Kie AI. Keep the cost reasonable and show me the plan before spending credits.
```

## Poster with readable text

```text
Using Kie AI, create a 3:4 poster-style image of a coffee shop storefront. The sign must read exactly "Bean There" in clean, readable lettering. Pick a model that is currently suitable for text rendering and explain the choice.
```

## Image-to-video from a public image

```text
Use Kie AI to animate this image into a short cinematic clip: https://example.com/reference.png. Add subtle camera movement and natural motion. Use a cost-conscious draft first.
```

## Narrated product demo

```text
Create a polished voiceover for this script using Kie AI: "Meet Flowly, the calendar that plans itself." Then create an image-to-video product clip from https://example.com/logo.png. If the first-choice video model is degraded, use an appropriate fallback and tell me what changed.
```

## Dry run only

```text
Plan a 10-second product trailer using Kie AI, but do not call any paid API. Show the current model choices, exact payloads, commands, task lifecycle, and fallback plan that I could run myself.
```

## Multi-step social ad

```text
Create a vertical 9:16 social ad using Kie AI. Generate a hero image first, animate it into a short video, create matching background music, then combine the final assets locally. Confirm each expensive stage before spending significant credits.
```
